# DAVIBELODESIGN

Site + painel admin para HostGator (PHP).

## Publicar na HostGator

1. Envie **todos** os arquivos para a pasta do domínio (`davibelodesign.com.br`), mantendo a estrutura.
2. Garanta permissão de escrita em `data/` e `uploads/` (755 ou 775).
3. Acesse o site: `https://davibelodesign.com.br`
4. Admin: `https://davibelodesign.com.br/admin/`

### Login inicial do admin

- Usuário: `admin`
- Senha: `Davibelo@2026`

Troque a senha em **Admin → Senha** assim que entrar.

## O que o painel edita

- Logo / cabeçalho / e-mail / redes
- Hero (PT e EN)
- Manifesto e objetivo
- Cards de projetos + upload de imagens
- Serviços
- Processo
- CTA / contato
- Senha do admin

No site, use o botão **PT / EN** no topo para trocar o idioma.
